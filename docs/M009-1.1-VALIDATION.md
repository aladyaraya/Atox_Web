## 运维及限制

第一次使用优化后的审核必须选择活动、由有效管理员配置窗口并填写原因；两类管理员均可操作。未配置或关闭时页面／历史／附件可读，所有审核、撤回及协调写入被拒绝。公众下架与后台审核窗口独立，恢复审核不会恢复公众发布。

保留现有 PGlite 单进程限制，迁移／维护须与网站互斥；不能用删表、重置或重新 bootstrap 排错。按 Git 维护约定留存源码及迁移，不提交旧源码压缩包、密钥或用户数据。本次不发布、不承诺生产就绪，也不运行真实 Logto 容器集成测试。
