# 从电脑里的网站，到别人能访问的网站

给第一次负责网站发布的人阅读。当前先弄清楚路线与分工，暂不执行服务器部署、采购或正式开放。此前的技术配置保留备查，以后决定方案时再评估。

## 1. 我们现在在哪里

你目前在自己的电脑上运行、查看网站。localhost 指当前这台设备；别人打开同样的地址，会指向他们自己的电脑。GitHub 保存代码、方便协作，把代码传到 GitHub 本身不会让这个全栈网站自动公开。

以后要找一个持续运行网站的地方，让它有正式网址，再确认真实用户能正常使用。

## 2. 这些名称是什么意思

| 名称 | 大白话解释 | 本项目为什么需要 |
| --- | --- | --- |
| 域名 | 用户输入的网址 | 让别人记住和访问官网 |
| 云服务器 | 租用的一台远程电脑，持续运行网站 | 不依赖你的个人电脑开机 |
| 数据库 | 网站的记录本 | 保存账号、报名、项目、评论等 |
| 文件存储 | 网站存附件的地方 | 保存封面、截图、PDF 等 |
| 验证码邮件服务 | 网站自动发邮件的通道 | 给用户发送登录验证码 |
| HTTPS | 网站的加密访问方式，地址以 https 开头 | 保护浏览器与网站间的信息传输 |
| 备份 | 另存一份能用来恢复的数据 | 故障时恢复账号、报名和附件 |

初期可以把网站与数据库放在同一台服务器，附件和备份另存。这是此前讨论的候选方案，具体规格、地区仍需确认。

## 3. 后面按什么顺序做

| 步骤 | 做什么 | 你负责什么 | 技术维护者负责什么 | 做完得到什么 |
| --- | --- | --- | --- | --- |
| ① 本机验收和内容确认 | 从访客、参赛者、管理员角度试用 | 确定首发功能；提供真实品牌、首页和首场活动资料 | 修复发现的问题，整理版本 | 明确的首发功能／内容清单 |
| ② 负责人和预算 | 确定谁拥有资源、谁运营、谁维护 | 指定负责人，给出月预算范围、域名候选 | 估算需要的服务并解释取舍 | 足够用于询价的信息 |
| ③ 选方案、拿报价 | 比较地区、配置和各项费用 | 看懂方案后确认选择，核对首期和续费 | 给出具体可购买选项、完整费用构成 | 公司认可的采购表 |
| ④ 建小范围测试站 | 确认方案后才开短期资源，网站加访问密码 | 用公司账号购买已确认资源并授权，提供测试人员 | 配好域名、邮件、数据库、存储和备份 | 外部测试人员能打开的受保护链接 |
| ⑤ 真实使用测试 | 国内外人员试用，技术人员做承载及恢复测试 | 先邀约 10—20 位测试者，反馈收信、报名、提交体验 | 修复问题，模拟多人使用，演练数据恢复 | 测试报告及是否可以开放的判断 |
| ⑥ 正式开放 | 确认资料、规则、联系人和测试结果 | 决定开放日期，运营准备接待用户 | 发布确认版本，解除测试访问密码 | 用户通过正式网址使用官网 |
| ⑦ 持续维护 | 检查费用、故障、数据及内容 | 处理活动运营、用户反馈和续费 | 处理更新、备份、告警和故障 | 网站能够持续运营 |

现在先做①—②。③以后再进入选型、采购。付款、开放访问或使用公司账号前，先提供具体且可核对的操作说明。命令、密钥和数据库操作交给技术维护者，你不需要先学会这些才能做决定。

## 4. 你现在只需先整理什么

此前已确认：公司／组织名义运营、免费公开、国内外用户均可使用、首发邮箱验证码登录。累计约 10000 个账号、300 人同时使用是规划中的测试目标，不代表已经实测通过。这些方向保留，不需要重新回答。

- 网站叫什么、谁来运营：公司／组织名称，正式品牌是否继续用 HACKATHON。
- 第一次活动是什么：主题、时间、预计报名人数，国内和海外用户大致分布。
- 首发开放什么：沿用免费邮箱登录、活动报名／材料、项目投稿／互动及后台的方向，实际试用并确认；未确定的单列。
- 愿意投入多少：每月预算先给范围，实际费用以后看报价和用量。
- 谁能协助：谁管云账号和付款，谁运营，谁承担技术维护，可以是不同的人。

目前不需要在聊天中提供密码、验证码或任何云账号密钥。

## 5. 以后需要采购什么

通常涉及域名、服务器、文件存储、验证码邮件、备份和监测。初期候选方案不另买托管数据库，由技术人员在服务器维护 PostgreSQL。报价填写 [资源询价表](../deploy/PROCUREMENT.md)。

核数、内存、磁盘和流量额度，由技术人员按预计规模提出选项。“4 核 8GB”不是你现在必须购买的答案。香港也是候选，国内外访问先实测；参见 [官方地域及网络说明](https://help.aliyun.com/zh/simple-application-server/product-overview/regions-and-network-connectivity)。
