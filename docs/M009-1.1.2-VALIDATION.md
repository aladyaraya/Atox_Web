## 问题与确认

用户反馈审核被时间设置锁死、材料总表不明显。复核确认此前按“未配置默认只读”实现，当前用户已改为默认跟随活动起止，并允许不限时／自定义。原总表存在，但筛选、时间说明及大统计卡占据首屏，标题和空数据说明不清楚；手机截图还发现 table caption 被挤成竖排。

本次统一后台首页与侧栏名称为“材料审核总表”，地址仍为 `/admin/materials`。正式材料区增加明确标题、数量和定位入口，辅助筛选折叠，时间与统计压缩；活动／状态选择立即应用，搜索保持防抖，详情返回、分页、统计口径和 URL 条件保留。手机卡片标题修复，不依赖横向滚动寻找记录。

## 时间与兼容

- 无策略：`mode=event`，使用当前已发布活动 startsAt/endsAt，开始包含、截止不包含；返回修订 0，不自动写策略记录。下架保留最后发布日期，未发布改期不影响当前审核。
- `unlimited`：不受活动日期限制，可手动暂停；`custom`：保留独立起止，启用需要未来截止。所有模式保留权限、必填原因、修订冲突和原子审计。
- 共同写服务及实际 SQL 更新的截止检查覆盖审核、撤回、协调和旧 M002 受理；未设置策略时可以正常写入。选手上传／草稿／重提仍按原提交期，不因不限时审核延长。
- 0011 追加 mode 及日期约束，旧配置按 custom 保留，0000—0010 未改。无新增环境变量；不更改认证、OIDC、活动发布及首页内容流程。
